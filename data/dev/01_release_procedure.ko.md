# DMS 릴리스 절차서(v2.4.0)

## 1. 개요

본 문서는 배송관리시스템(DMS) v2.4.0을 운영 환경에 릴리스하는 절차를 정한 것입니다.
작업은 2026년 11월 14일(토) 22:00~익일 2:00 정기 점검 시간 내에 실시합니다.

## 2. 사전 준비

- 스테이징 환경에서의 인수 테스트가 완료되고 고객사의 승인을 받았을 것
- 야간 배치의 잡넷 `DMS_NIGHTLY`를 중지했을 것
- 롤백용 백업(약 120GB)을 취득 완료했을 것
- 작업 시작 30분 전까지 관계자에게 메일로 작업 시작을 연락할 것

## 3. 작업 절차

| No | 작업 | 담당 | 예상 시간 |
|---|---|---|---|
| 1 | 애플리케이션 서버 2대를 로드 밸런싱에서 분리한다 | 다카하시 | 10분 |
| 2 | `deploy.sh --env prod --version 2.4.0`을 실행한다 | 다카하시 | 20분 |
| 3 | 가동 확인을 하고 출고 지시 화면이 표시되는지 확인한다 | 김민수 | 15분 |
| 4 | 리포트 출력 결과를 지난 릴리스 때와 비교한다 | 김민수 | 30분 |

## 4. 롤백 판단

가동 확인에서 심각한 장애가 발견된 경우에는 작업 책임자가 롤백을 판단합니다.
판단 기한은 1:00으로 하고, 그때까지 해소할 수 없는 경우에는 이전 버전(v2.3.2)으로 되돌립니다.
자세한 내용은 https://wiki.example.com/dms/rollback 을 참조해 주십시오.

## 5. 작업 후 연락

작업 완료 후 결과를 이슈 관리표에 기록하고, 다음 날 아침 인수인계 때 공유합니다.
